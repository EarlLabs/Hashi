{# What every console mutation answers with. One template rather than one per action, because the SHAPE is always the same: something for the dialog slot (a new dialog, or nothing — which closes it), plus at most one out-of-band toast or banner. Keeping it in one place is what makes "every mutation emits a toast naming its object" (UI-PATTERNS §8) checkable by reading a single file. The out-of-band elements have to be TOP-LEVEL in the response for htmx to find them, which is why they are included here rather than nested inside a dialog. THE BANNER SLOT IS ALWAYS ANSWERED, with the failure or with nothing. That is what clears the last failure when the operator's next action works, and it is the server's job rather than the script's because the script cannot tell the two apart: it used to empty the slot on `htmx:afterRequest` for any successful exchange, which fires AFTER the swap — so every banner this file has ever sent was written into the slot and wiped again a moment later, and a probe that could not reach a node reported nothing at all. A table refreshing itself on a `-changed` event is a successful exchange too, which is why "clear it earlier" is not the fix either: only an answer that OWNS the slot can know whether it is meant to be empty. THREE THINGS CAN BE IN THAT SLOT SINCE M22.3, not two: a failure, a NOTICE, or nothing. The notice is the same element in the quieter weight, and it is here rather than as a longer-lived toast because a toast that outlived its 2200ms would be a second rule for one element — see panel/notice.html for what it is for and what it is not. Still exactly one of the three, so the slot's meaning is unchanged: whatever the last answer put there is what the operator is looking at, until the next one. A notice and a failure are mutually exclusive by construction below, so a caller that passes both gets the failure — the louder of the two, which is the safe way for that mistake to land. #} {% if dialog %}{% include dialog %}{% endif %} {% if toast %}{% include "panel/toast.html" %}{% endif %} {% if banner %}{% include "panel/banner.html" %}{% elif notice %}{% include "panel/notice.html" %}{% else %}
{% endif %}
