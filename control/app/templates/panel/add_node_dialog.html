{# "Add a node" — the Nodes screen's own creation flow. UI-PATTERNS §5: creation happens in a dialog, never inline on the page, and a dialog is title → fields → one sentence on the consequence → actions with cancel secondary and confirm primary. design/README.md sizes this one at 560px with its short fields in two columns and the key on its own row, which is `.dialog-wide` and `.grid-2` — the grid collapses under the one breakpoint that already exists (UI-PATTERNS §12). NOTHING HERE NAMES A HOST, A COUNTRY OR A PORT. That is M9's own rule and it is why the two SSH defaults arrive in `defaults` from services/nodes.py instead of being typed into this file: a value written into markup is one nobody can find when it has to change. The hints say what a box is for, in prose, and the boxes themselves are empty until the operator fills them. Re-rendered with `errors` set when the node is refused, so each message lands under the field it is about — M8.6, and every value the operator typed comes back with it. Every value EXCEPT the private key: see the note on that field. {# The one key this panel ever accepts, and it is write-only. UI-PATTERNS §9 and CLAUDE.md: where key material could appear, the panel states the rule instead. This box is the exception that proves it — it is how the control plane is given the credential for reaching the host, and it is stored encrypted and never rendered anywhere again. A transport's own keys are minted on our side and never typed into any form. Deliberately NOT refilled when this dialog comes back with an error, unlike every other field: putting a submitted private key back into the markup would make the panel a place key material appears, which is precisely what that rule forbids. The hint says so, and `key_dropped` says it AGAIN at the moment it happens — a static hint is not enough, because the operator whose NAME was refused is reading the message under the name, fixes that, resubmits, and registers a node with no key at all. The apply that cannot connect arrives much later and reads as a broken host. #}
