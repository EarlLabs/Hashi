Withdraw {{ offer.transport }}?
It leaves every user's link on {{ offer.node }} at their next refresh, and nobody re-imports anything. You can offer it again from the same place, and their link does not move either way.
The node keeps serving it until you apply the node: this changes what this panel hands out, not what the host is running, so anyone already holding a fetched configuration keeps connecting on it until then. To take one person's access away instead, revoke them on the Users screen — that is a different action with a different reach.
